# Дипломдық презентация (Тасқын PPTX құрылымына сәйкес)

Бұл құжат **`Тасқын дипломдық прзентация.pptx` слайд тәртібімен** дайындалған: әр төменгі тарау **PowerPoint-тегі бір слайдқа** көшіріледі. Мазмұн — **Task IN (akademportal)** жобасына сәйкес.

**Титулда** орындаған мен ғылыми жетекші аты-жөнін өз нұсқаңызбен ауыстырыңыз.

---

## 1-слайд. Титул

**ДИПЛОМДЫҚ ЖҰМЫС**

**Тақырыбы:** Студенттердің академиялық жұмыстарын орталықтандырылған сақтау және іздеуге арналған веб-порталды жобалау және іске асыру.

**Жоба:** Task IN (akademportal)

**Орындаған:** *(аты-жөніңіз)*

**Ғылыми жетекшісі:** *(аты-жөні, лауазымы)*

---

## 2-слайд. Тақырыптың өзектілігі

Қазіргі цифрландыру дәуірінде жоғары оқу орындарында студенттердің академиялық жұмыстарын электронды түрде сақтау және тиімді басқару маңызды мәселеге айналды. Дипломдық жұмыстар, курстық жұмыстар, ғылыми мақалалар, эсселер және жобалық жұмыстар көбіне әртүрлі құрылғыларда, жеке папкаларда, поштада немесе мессенджерлерде сақталады. Сондықтан кейіннан іздеу, тексеру, салыстыру және қайта пайдалану қиын.

Осыны шешу үшін академиялық жұмыстарды **бір орталық веб-порталға** жинау қажет. Мұндай портал студентке жұмысын жүктеуге, жетекшіге тексеруге, әкімшіге процесті бақылауға, ал барлық рұқсатты пайдаланушыларға **бекітілген** жұмыстарды іздеуге мүмкіндік береді.

---

## 3-слайд. Мақсаты

**МАҚСАТЫ**

Дипломдық жұмыстың басты мақсаты — студенттердің академиялық жұмыстарын **орталықтандырылған түрде сақтау**, **іздеу**, **рецензиялау** (жетекші арқылы) және **әкімшілікпен басқаруға** арналған заманауи **веб-порталды жобалау және іске асыру**.

---

## 4-слайд. Міндеттері (қысқа, түсінікті нұсқа)

**ДИПЛОМДЫҚ ЖҰМЫСТЫҢ МІНДЕТТЕРІ**

1. **Архитектура** — веб-технологиялар негізінде толық стек портал құру (интерфейс + API + дерекқор).  
2. **Кіру** — қауіпсіз тіркелу/кіру, рөлге байланысты құқықтар (студент, жетекші, әкімші).  
3. **Интерфейстер** — үш рөл үшін жеке панельдер мен беттер.  
4. **Жүктеу** — PDF және DOCX сақтау, өлшем мен форматты тексеру.  
5. **Мета** — атау, аннотация, түр, жыл, тіл, кафедра, жетекші, кілт сөздер.  
6. **Рецензия** — жетекшінің бағасы, пікірі, бекіту / қайтару / қабылдамау.  
7. **Іздеу** — бекітілген жұмыстарды мәтін және сүзгілер бойынша табу, сұрыптау.  
8. **Қосымша** — bookmark, хабарлама, профиль, баптаулар.  
9. **Әкімші** — пайдаланушылар, жұмыстар, факультет/кафедра, жетекші өтінімдері.  
10. **Сапа** — тестілеу, қателерді түзету, пайдалануға дайындау.  

---

## 5-слайд. Веб-порталды жүзеге асырудың негізгі кезеңдері

**НЕГІЗГІ КЕЗЕҢДЕР**

**1.** Пайдаланушылар мен рөлдер анықталды: студент жүктейді, жетекші рецензиялайды, әкімші басқарады.

**2. Технологиялар стегі**

| Топ | Технология | Неге керек (қысқа) |
|-----|------------|---------------------|
| Клиент | **Next.js 14** | Беттер, маршруттар, серверлік компоненттер, өндірістік құрастыру. |
| Клиент | **React 18** | Интерфейс компоненттері, күй басқару. |
| Клиент | **TypeScript** | Типтер арқылы қателерді ерте ұстау. |
| Клиент | **Tailwind CSS** | Жылдам, бірыңғай стиль (utility-кластар). |
| Клиент | **lucide-react** | Біркелкі иконкалар. |
| Клиент | **framer-motion** | Жеңіл анимациялар, жақсы UX. |
| Сервер | **Next.js Route Handlers** | `/api/...` сұрауларын өңдеу (REST API). |
| Дерек | **Prisma ORM** | PostgreSQL-ге типтеп қорғалған сұраулар. |
| Дерек | **PostgreSQL** | Негізгі сенімді РСҚБ. |
| Қауіпсіздік | **NextAuth** | Кіру сессиясы. |
| Қауіпсіздік | **bcryptjs** | Парольді хэштеу. |
| Тексеру | **Zod** | Форма және API денесін валидациялау. |

**Қосымша (жобада):** іздеу үшін **Elasticsearch**; сервер өшік болса **PostgreSQL** арқылы іздеуге өту; деплой үшін **Docker**, **Vercel** немесе **Render**.

**3.** **Prisma schema** — User, Work, Review, Faculty, Department, Keyword, Bookmark, Download, Notification, Audit т.б. модельдер байланыстырылды.

**4.** Интерфейс пен API жетілдірілді; іздеу индекстеу мен әкімшілік сүзгілері орнатылды.

---

## 6-слайд. Қолданбаның дерекқормен әрекеттесуі

**PostgreSQL** — негізгі дерекқор. **Prisma ORM** модель мен сұрауларды TypeScript-пен үйлестіреді.

**Логика қысқаша:** тіркелу → `User`; жұмыс жүктеу → `Work`; рецензия → `Review`; жұмыс бекітілгенде → іздеу индексі; bookmark → `Bookmark`; күй өзгерісі → `Notification`.

---

## 7-слайд. Кіру және тіркелу беті

Пайдаланушы **email және пароль** арқылы тіркеліп, кіреді. **NextAuth** әдістемесінде кіру рәсімі ұйымдастырылған; пароль **bcryptjs** хэш түрінде сақталады.

Тіркелуде **студент** немесе **жетекші** таңдалады. **Жетекші** аккаунты әкімші **бектірмейінше** толық белсенді болмайды.

---

## 8-слайд. Басты бет және dashboard

**Студент** — өз жұмыстарының мәртебесі, хабарламалар, жүктеу/іздеуге өту.  
**Жетекші** — тағайындалған жұмыстар, рецензия тарихы.  
**Әкімші** — оқу орны деңгейіндегі басқару орталығы.

---

## 9-слайд. Академиялық жұмыстар бөлімі

Студент жүктеген жұмыстарды **мәртебемен** көреді. Жаңа жұмыс: **PDF немесе DOCX**, метадеректер. **Өлшем**, MIME, кеңейтім және **файл сигнатурасы** тексеріледі.

---

## 10-слайд. Жұмыс қарау және бағалау беті

Жұмыс карточкасында атау, аннотация, автор, факультет, кафедра, жетекші, жыл, тіл, түр, кілт сөздер, файл ақпараты, қаралым/жүктеу көрінеді.

**Жетекші** бекітеді, түзетуге қайтарады немесе қабылдамайды; қайтару/бас тартуда **себеп** көрсетіледі.

---

## 11-слайд. Іздеу жүйесі

Мәтіндік іздеу; **түр**, **факультет**, **жыл**, **тіл**; **сұрыптау** (өзектілік, күн, жүктеу, рейтинг). Студент **барлық бекітілген** жұмыстар каталогын іздей алады.

---

## 12-слайд. Профиль беті

Аты-жөн, email, факультет, қызығушылықтар, байланыс; avatar, bio, әлеуметтік сілтемелер жаңартылады.

---

## 13-слайд. Баптау беті

Жеке параметрлер: профиль өрістері, тақырып (жарық/қараңғы) т.б.

## 15-слайд. Қорытынды + болашақ

**Болашақ:** семантикалық іздеу; плагиат сервисін кеңейту; **S3 / MinIO** сияқты object storage; есептер, экспорт; басқа Жүйелермен интеграция.

**Қорытынды:** **Task IN** веб-технологияларды академиялық процеспен ұштастырып, сақтау, іздеу және тексеруді бір орталықтан ұйымдастырады.

# Қосымша: стек суретіндегі технологиялар — анық түсіндіру

Мұны **5-слайдқа қосымша** немесе бөлек ақпараттық слайдқа қысқартып қоюға болады.

### Frontend

- **Next.js 14** — React негізіндегі full-stack фреймворк: `app` маршруттары, сервер және клиент компоненттері, бір жобада API; дипломдық порталды біртұтас әзірлеуге ыңғайлы.  
- **React 18** — интерфейсті компоненттерге бөлу, күй және оқиғалар арқылы басқару.  
- **TypeScript** — типтер арқылы код сенімділігі; API пішіндері мен модельдерді келісу оңайласады.  
- **Tailwind CSS** — utility-кластармен жылдам стильдеу, бір дизайн тілі барлығына.  
- **lucide-react** — иконкалар жинағы, визуал біркелкілік.  
- **framer-motion** — жеңіл анимация: экран элементтері жұмсақ ауысады, пайдаланушы тәжірибесі жақсарады.

### Backend және API

- **Next.js Route Handlers** — `route.ts` ішінде HTTP әдістері: бөлінген серверсіз REST API; деплой жолы қарапайым, маршрут пен код жақын.  
- **Prisma ORM** — PostgreSQL кестелері кодтағы модельдермен байланыстырылады; сұраулар типтелген; миграция арқылы схема нұсқалары сақталады.  
- **PostgreSQL** — реляциялық дерекқор: User–Work–Review сияқты байланыстарды сенімді сақтау.  
- **NextAuth** — кіру сессиясы, тіркелу провайдері, серверде сессияны тексеру.  
- **bcryptjs** — парольді хэштеу; дерекқорда ашық пароль болмауы керек.  
- **Zod** — кіріс дерек схемасы; API мен формаларда валидация — қате деректерді ерте қайтару.
